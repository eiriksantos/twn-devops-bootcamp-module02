# 🖥️ Operating System 101 — A Quick Primer

## 1. What is an Operating System (OS)?
An **Operating System (OS)** is the core software that manages a computer’s hardware and provides an environment for applications to run.  
It acts as the **bridge** between the user, application software, and the hardware components of a system.

---

## 2. Main Functions of an OS

- 🧠 **Resource Management:** Allocates and manages CPU, memory, storage, and input/output (I/O) devices among applications.  
- ⚙️ **Process Management:** Handles the creation, execution, and termination of running programs (processes).  
- 💾 **Memory Management:** Keeps track of which part of memory is in use and by which process, ensuring efficient and safe memory access.  
- 📁 **File System Management:** Organizes and controls how data is stored and retrieved on disks.  
- 🔐 **Security & Access Control:** Protects system resources and enforces permissions and authentication.  
- 🧩 **User Interface:** Provides command-line or graphical interfaces for users to interact with the system.

---

## 3. Relation Between OS, Applications, and Hardware

The OS acts as the **middle layer** connecting software to hardware:

- **Applications** request services (like saving a file or allocating memory) through the **OS**.  
- The **OS** translates those requests into hardware instructions.  
- This allows applications to run without directly managing the complexity of the hardware.

---

## 4. In Short

The **Operating System** is the **heart of the computer system**, coordinating hardware operations and providing a stable, consistent environment where **application software** can run efficiently and safely.
