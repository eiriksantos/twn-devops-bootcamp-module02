# Users and Permissions Part 1
## Linux Accounts and Groups

### Account Types
#### Superuser Account
- Known as Root User
- Has unrestricted permissions

#### User Account
- A regular user we create to login
- Has its own dedicated space e.g. */home/user1*

#### Service Account
- A user for services running on the server e.g. MySQL, Apache, etc
- Each service will get its own user for isolation purposes
- **DO NOT** run services with root user!!
